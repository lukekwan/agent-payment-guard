# Free-plan publication checklist

## Contract

- [ ] PM approves the six-endpoint allowlist and authority labels.
- [ ] Product owner resolves the Agent Payment price conflict.
- [ ] Auth owners approve candidate schemes/scopes; no scope is inferred.
- [ ] Risk/evidence owners approve scores, reliability, rules, freshness, and retention.
- [ ] Envelope remains non-binding or receives a separately versioned /v2 decision.

## Content and samples

- [ ] Request, success, error, and six scenario fixtures validate.
- [ ] cURL, JavaScript, and Python syntax pass.
- [ ] No secret, internal route/scope, invented price, or live Test it.
- [ ] Changelog is external-only; Help Center is SignGate-specific.
- [ ] Every CTA is safe-sample or browse-only.

## GitBook Basic QA

- [ ] Change Request preview renders the branch.
- [ ] Desktop Home, Documentation, API Reference, Changelog, Help Center captured.
- [ ] Mobile overflow, zh-TW wrapping, and WCAG AA contrast pass.
- [ ] Search finds all five services.
- [ ] Variant remains unconfigured until language approval.
- [ ] No paid feature, purchase, merge, or publication occurs.

PM, QA, security reviewer, and Founder approvals are mandatory. Merge and publish are separate explicit actions.
