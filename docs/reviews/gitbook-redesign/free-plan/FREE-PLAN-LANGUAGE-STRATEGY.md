# Free-plan language strategy

## Release decision

English is primary. Traditional Chinese content is retained but is not appended as a full duplicate tree in SUMMARY.md.

## Verified evidence

The current Site structure screen exposes Add variant without an upgrade badge. Its dialog can select a Space, set a title, and says the variant starts as a draft. This proves configuration access, not the complete public result.

## Phase 1

Use one English public site and one clearly linked zh-TW landing/status page. Preserve existing zh-TW source files for parity work without exposing an oversized bilingual sidebar.

## Phase 2 gate

Create a Traditional Chinese Space/Variant only after QA verifies creation, draft preview, public switch, stable URLs, search, canonical/hreflang, analytics, mobile navigation, and no accidental publication on the current plan.

No Variant was created because site-structure mutation and publication were not authorized.

## Parity map

Home, Documentation, API Reference, Changelog, and Help Center each require an owner, English canonical slug, zh-TW target slug, reviewed translation status, and last contract revision before zh-TW publication.
