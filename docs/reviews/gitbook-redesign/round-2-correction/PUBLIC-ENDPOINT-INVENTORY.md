## Method and counting boundary

The audit cross-checked `src/index.js`, tests, packages, SDKs, both candidate OpenAPI files, the current GitBook source, production `/openapi.json`, `/catalog.json`, `/.well-known/x402`, `/.well-known/mcp.json`, and safe unauthenticated runtime probes. `ROUTES_DISCOVERED=100` counts the primary API/service method-path operations below. Public discovery and presentation aliases are recorded separately and do not inflate that number.

The production snapshot contained **86 paths / 87 OpenAPI operations**, **83 catalog products**, and **85 x402 paid operations**. The branch generates 79 paths / 80 operations and 73 products / 75 paid operations. All 83 production catalog example URLs returned HTTP 402 without payment. No payment was made and no stateful production request was sent.

Column groups deliberately combine the required fields so each endpoint remains one row:

- **Host / auth / scope** = runtime host, authentication, required scope.
- **Implementation / route evidence** = implementation state and source/handler evidence.
- **OpenAPI / catalog** = both statuses.
- **Effect / browser** = side effect and safe-for-browser-Test-it assessment.
- **Authority / docs** uses only the required authority vocabulary and states the documentation action.

Abbreviations: `prod` = production host above; `n/a` = no separately declared scope; `OA` = OpenAPI; `RT` = runtime. `conditional` means the browser may demonstrate the request or an unpaid 402 challenge, but must not automatically pay or retain a credential.
