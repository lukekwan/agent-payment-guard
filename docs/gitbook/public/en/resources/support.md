# Support and contact

Provide identifiers and symptoms without sending API keys, raw secrets, or prohibited action content.

{% hint style="info" %}
**Primary constraint:** Support cannot override a decision or authorize execution.
{% endhint %}

## Include

- UTC timestamp
- Preview environment identifier
- HTTP status
- Request ID
- Decision and audit IDs when available
- Reason codes
- Redacted client and executor logs

## Do not include

Authorization headers, API keys, private keys, tokens, environment files, raw secret values, or full sensitive payloads.

## Contact

Use the authorized Nomos Labs integration support channel associated with your preview access.

## Request access

To request preview access, include your company name, integration use case, expected agent action types, target environment, and whether the agent will touch payments, production data, credentials, permissions, or external services.

Email: [hello@nomos-labs.xyz](mailto:hello@nomos-labs.xyz)

## Contact us

For partnership, integration review, or developer documentation questions, contact Nomos Labs with a short description of what you want the agent to do and which execution boundary needs review.
