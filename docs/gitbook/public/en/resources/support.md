# Support and contact

Provide identifiers and symptoms without sending API keys, raw secrets, or prohibited action content.

{% hint style="info" %}
**Primary constraint:** Support cannot override a decision or authorize execution.
{% endhint %}

## Include

- UTC timestamp
- Preview environment identifier
- HTTP status
- Request ID
- Decision and audit IDs when available
- Reason codes
- Redacted client and executor logs

## Do not include

Authorization headers, API keys, private keys, tokens, environment files, raw secret values, or full sensitive payloads.

## Contact

Use the authorized Nomos Labs integration support channel associated with your preview access.
