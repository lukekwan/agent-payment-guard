# Help Center

## Before you contact support

- Confirm whether a page describes a verified current route or a proposed candidate.
- Do not expect a sandbox key or isolated sandbox Base URL; neither flow is verified.
- Preserve the exact decision vocabulary returned by the service.
- For x402 wrappers, inspect the payment challenge before retrying.
- Treat unavailable evidence as unavailable, never as low risk.
- Never paste API keys, payment proofs, private keys, or production payloads into a support request.

## Topics

API key/authentication status; sandbox/production availability; decision interpretation; rate limits/retries; pricing/credits/x402; common errors; integration troubleshooting.
